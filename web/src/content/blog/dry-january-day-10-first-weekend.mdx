By Day 10 of Dry January, the novelty is gone. You’ve survived the weekday routine. Now comes the first weekend — the real test.

This post is a tactical plan for Friday night through Sunday.

## Friday: protect the trigger

Friday is when “I deserve it” shows up. Replace the reward with something else:

- Longer dinner, better food
- A film or game you’ve been saving
- A walk or gym session that feels like a reset
- Early night if you’re tired

Track the drinks you skipped and see the money saved in the app. Proof of the new reward.

## Saturday: the social event

If you’re going out:

- Eat before you go
- Order a non-alcoholic drink first
- Have a one-liner ready: “I’m on Dry Jan, tonic for me.”
- Set a time limit
- Leave before people get sloppy

If you’re staying in, make it intentional. Plan the evening so it doesn’t feel like deprivation.

## Sunday: the reset

- Wake up clear, log the streak
- Count twin gains for the weekend
- Prep for the next week (grocery shop, meal prep, schedule)
- Note one trigger you avoided

## Emergency script if you feel close to slipping

Pause and ask: “What do I actually want right now?”

- Relaxation? Take a bath, walk, or 10-minute meditation
- Social connection? Call a friend who supports the goal
- Reward? Buy something small with the money saved
- Boredom? Start a show, game, or project

Usually the drink is a delivery mechanism for something else.
